# AI Study Assistant — Prompt Engineering

## Project Overview

This project demonstrates how prompt engineering techniques can be used to design an AI Study Assistant that provides clear, structured, and personalized learning support.

The project focuses on improving a basic prompt by applying structured prompt engineering techniques, including the CARE framework.

## Objective

To design and evaluate prompts that help an AI assistant:

- Explain academic concepts clearly
- Generate practice questions
- Summarize learning material
- Adapt explanations to the learner's level
- Provide structured and useful responses

## Prompt Engineering Approach

The project compares a simple prompt with a structured prompt using the CARE framework:

**C — Context** 
Provide relevant background information.

**A — Ask** 
Clearly define what the AI should do.

**R — Rules** 
Specify requirements, constraints, and response format.

**E — Examples** 
Provide examples when they help guide the expected response.

## Test Scenario

**Topic:** Newton's Laws of Motion

**Learner Level:** Diploma Engineering Student

**Goal:** Explain the concept in a simple and understandable way.

## Basic Prompt

Explain Newton's Laws of Motion.

## Improved Prompt

You are an experienced engineering tutor.

Explain Newton's Laws of Motion to a Diploma Engineering student.

Use simple language and explain each law separately.

For each law:

1. Give the definition.
2. Explain the concept in simple words.
3. Give one practical engineering-related example.

Keep the explanation structured with headings and bullet points.

At the end, provide 5 practice questions to test understanding.

## Expected Outcome

The structured prompt should produce a more organized, learner-focused, and useful response than the basic prompt.

## Key Learning

This project demonstrates how providing context, clearly defining the task, setting rules, and specifying the desired output can improve the quality and consistency of AI responses.
